# Fast-Scroll-Extension

Scrolls your X History page down fast with one button. Press it again to stop.

## Install

1. Get the code: [github.com/SabirinAbdi/Fast-Scroll-Extension](https://github.com/SabirinAbdi/Fast-Scroll-Extension)
2. Open `chrome://extensions` and turn on **Developer mode**
3. Click **Load unpacked** and pick the folder with `manifest.json`
4. Open X → History and hit **Scroll ↓**

## Notes

- Works on History and Bookmarks, both fine.
- If it pauses to load posts, let it run — it'll keep going.
- Extension is just `manifest.json` + `content.js`. That's it.
